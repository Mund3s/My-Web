# My-Web

Portafolio personal de Carlos Mauricio Campos Gutiérrez. Es un sitio estático (HTML, CSS y un poco de JavaScript) listo para GitHub Pages.

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

## Publicar en GitHub Pages

1. En el repositorio, ve a **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. El sitio quedará en `https://mund3s.github.io/My-Web/`.

## Estructura

- `index.html`: contenido (sobre mí, proyectos, experiencia, contacto).
- `styles.css`: estilos, con modo claro y oscuro automático.
- `script.js`: menú en móvil y año del pie de página.
- `assets/`: imágenes.
